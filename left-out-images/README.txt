LEFT OUT - scene images (244 images, 2 per timestamp, 16:9)

File names = timestamp in the script, then _1 or _2 for the two versions.
  e.g. 0-00_1.png and 0-00_2.png = the 0:00 timestamp
       10-29_2.png               = second image for 10:29
(":" isn't allowed in Windows file names, so "-" is used instead.)

HOW TO DOWNLOAD ALL IMAGES WITH THE RIGHT NAMES
  Windows: double-click download_images_windows.bat
  Mac/Linux: open Terminal in this folder and run:  sh download_images.sh
The images will be saved in a new "images" folder.

manifest.csv lists every file name and its download link, if you prefer to grab them by hand.
character_reference.png is the main caveman reference sheet used for consistency.
